# 시연 흐름 — 화면별로 조작해서 보여줄 것

화면 순서대로, 각 화면에서 "만져서 보여줄 수 있는" 인터랙션.

## 1. 로그인
- 카카오·네이버 **간편 로그인** 버튼 → 온보딩으로
- 비밀번호 표시(눈 아이콘) 토글
- 하단 **"비회원으로 둘러보기"** → 지도로 바로

## 2. 기본조건 설정 (Setup) — 조작 볼거리 많음
- **보증금·월 임대료 슬라이더 드래그** → 값 실시간 반영
- **지역 칩** 추가(+ 지역 추가)·삭제, 최대 3개
- **방 구조·건물 유형 칩 중복 선택**
- 임대유형·준공연도·면적 **드롭다운**
- **"고급 설정" 펼치기**(▾) → 소득구간·공급계층·우선공급 등 세부 조건
- 하단 **조건 통과 후보 수** 피드백 → "완료하고 취향 비교"

## 3. 취향 비교 (Swipe) — "어떤 일상이 더 끌리나요?"
- 두 **가상 생활권 카드(A/B)** 중 하나 선택 → 다음 문항 (각 카드에 "취향 학습용 가상 매물" 배지·문장형 타이틀·감수할 점·"내 예산·면적·필수조건 충족")
- "둘 다 비슷해요 / 둘 다 내 생활과 달라요" 응답
- **"이전 질문"** 으로 돌아가 선택 수정 → 취향 재계산
- 마지막 **취향 진단**(우선/보통/탐색중/후순위) + **직접 보정**(우선순위·끄기·다시하기)

## 4. 지도 — 인터랙션 핵심
- **빠른 필터 토글**: 보증금(3천/5천/1억)·준공(5·10·15년)·적합도(90/80/70) 프리셋 눌러 즉시 좁힘
- **정렬 토글**: 적합도순 ↔ 보증금 낮은순
- **지도 줌 인/아웃** → 개수 클러스터가 합쳐지고 갈라짐
- **마커 클릭** → 우측 리스트에서 해당 단지 하이라이트
- 리스트 **스크롤**, 화면 이동하면 리스트도 화면 내 매물로 갱신
- 카드 **하트로 찜**

## 5. 상세
- **탭 전환**: 기본 / 비용 / 주변인프라 / 교통
- 생활취향 적합도 + 추천 이유(결합태그·"도시철도 400m·카페 다수" 등 거리·개수 근거) + "자격·당첨확률 아님" 안내
- 관심(하트) · 공유(링크 복사) 버튼

## 6. AI 검색 — 핵심
- 문장 입력 → **조건 칩으로 분해**, 칩 **개별 제거** 가능
- 우측 **예시 문장 클릭**해서 바로 검색
- "이 조건으로 N곳" (실제 엔진 카운트)
- 0건이면 **완화 제안** ("예산 높이면 N곳")
- 모순/모호 입력 → **"이 부분은 이해 못했어요" 되물음**
- (찜한 게 있으면) 빈 화면의 **"찜하신 곳처럼 찾아보기" 선제 제안** 원클릭

## 7. 관심 · 마이페이지
- 하트 찜/해제 → **실행취소 토스트**
- 관심목록 모아보기
- 조건 저장/재적용

---

**주의:** 6의 AI 개인화·완화 제안은 **백엔드+Gemini 키(실모드)** 에서만. env 없는 데모 목(MSW)이어도 생활취향 적합도·근거는 `tag/` 산출물이 `generated/housings.json`에 실려 정적으로 보이고(개인 가중은 프론트 로컬 계산), AI는 요약만.
